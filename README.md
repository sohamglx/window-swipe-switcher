# GNOME Window Swipe Switcher

A GNOME Shell extension for switching between individual windows using touchpad swipe gestures.

***Use Three Fingers to switch between running app's windows***

## Status

Experimental — gesture handling and compatibility are still being tested.

## Installation

Clone this repository and copy the extension into your GNOME Shell extensions directory.

## Compatibility

GNOME Shell 50 — testing in progress.
